cards, the catalogue table (577-10: one row per block and sample, Preview opens `/showcase/<lang>/preview/<id>` — crumbs and one block; rows and the numbers of the metrics come from `app/showcase/_data/catalogue-rows.ts`), the agent flow and the FAQ. of blocks v0.5.24; the registry is read through `@reg/*` (`.registry-view/`, `scripts/registry-view.mjs`). Words — `body.i18n.ts`.
